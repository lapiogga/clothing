# 화면 명세서

## 공통 UI 디자인 가이드 (v4.0, 2026-02-24)

### 디자인 테마
- **테마 유형**: 정부/공공기관형 (밝고 정형화된 사무적 톤)
- **색상 체계**: 흰색 배경, 감청색 Primary (#1D4ED8 계열, oklch), zinc 무채색 보조
- **사이드바**: 짙은 남색 (`oklch(0.240 0.080 261.0)`)
- **헤더/사이드바 배경**: 옅은 베이지 (`#FAF7F2`)

### 타이포그래피
- **본문 폰트**: `"Arial", var(--font-noto-sans-kr), sans-serif`
- **고정폭 폰트**: `"Arial", var(--font-noto-sans-kr), sans-serif` (주문번호 등)
- **폰트 크기**: 0.9375rem (15px)
- **줄간격**: 1.4 (콤팩트)

### 버튼 (Button) 스타일
- **모서리**: `rounded-[4px]` (4px 모서리)
- **기본 (default)**: 감청색 배경, 흰색 텍스트
- **outline**: `border-zinc-300 bg-zinc-100 text-zinc-700`
- **secondary/수정/검색/추가**: zinc 배경색 적용 (배경 있는 스타일)
- **destructive/삭제**: `bg-zinc-600 text-white`

### 배지 (Badge) 스타일
- **모서리**: `rounded-[2px]` (2px 모서리, 사각형에 가까운)
- **색상**: 무채색 zinc 계열 (default: zinc-600 흰글, secondary: zinc-200 어두운글)

### 금액 표시
- 우측 정렬 (`text-right`)
- 고정폭 숫자 (`font-variant-numeric: tabular-nums`)

## 공통 레이아웃

### 헤더 (Header)
- **좌측**: 시스템 로고/명칭 "피복 구매관리 시스템"
- **중앙**: 대메뉴 (Pull-Down 방식, 역할별 표시)
- **우측**: 사용자 정보 (이름, 역할), 로그아웃 버튼
- **높이**: 고정 (sticky top)
- **배경색**: 옅은 베이지 (`#FAF7F2`)

### 메뉴 구조
- **군수담당자**: 대시보드 | 사용자관리 | 포인트관리 | 품목관리 | 기초데이터 | 체척권관리 | 시스템
- **피복판매소**: 대시보드 | 오프라인판매 | 온라인주문 | 재고관리 | 배송지관리 | 통계
- **체척업체**: 대시보드 | 체척권등록 | 체척권현황
- **일반사용자**: 쇼핑 | 구매내역 | 포인트 | 체척권

- 등록/수정: 폼 Dialog

- 성공: "처리되었습니다"
- 에러: 구체적 에러 메시지
- 위치: 우측 상단
