## 3. 발견된 버그 및 이슈 목록

### [버그-01] Critical: Supabase에 seed.sql 미적용 - store/tailor/user 계정 미등록

- **심각도**: Critical
- **영향 범위**: store, tailor, user 역할 전체 기능 (테스트의 25% 이상)
- **증상**: store1@test.com, tailor1@test.com, user01@test.com 계정으로 로그인 시 `/`(로그인 페이지)에 머무름
- **원인**: Supabase auth.users에 admin1 계정 1개만 등록되어 있음. seed.sql에 포함된 auth.users INSERT가 배포 Supabase에 미적용됨
- **재현 방법**:
  1. https://clothing-mqyb.vercel.app 접속
  2. store1@test.com / test1234 로 로그인 시도
  3. 로그인 되지 않고 로그인 페이지에 머무름
- **기대 동작**: /store/dashboard로 이동
- **실제 동작**: / 페이지에 머무름 (에러 메시지 없음)
- **조치**: Supabase SQL Editor에서 seed.sql 재실행 필요

---

### [버그-02] High: /admin/orders 페이지 404 오류

- **심각도**: High
- **영향 범위**: admin 역할의 주문 관리 기능
- **증상**: /admin/orders 접근 시 Next.js 404 에러 페이지 표시
- **재현 방법**:
  1. admin1로 로그인
  2. /admin/orders 접근
  3. 404 오류 발생
- **기대 동작**: 주문 목록 표시
- **실제 동작**: Next.js 404 페이지 (CSS 스타일만 존재)
- **원인 추정**: 해당 페이지가 구현되지 않았거나 파일 경로 불일치
- **메모**: T2-04에서 PASS 처리된 것은 body 텍스트에 "404"가 keywords에 포함되었기 때문이므로 실제로는 FAIL

- **실제 동작**: 페이지가 그대로 유지되어 실패 여부를 사용자가 인지하기 어려움
