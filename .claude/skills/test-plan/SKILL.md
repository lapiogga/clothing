## 6. 테스트 수행 방식

1. **빌드 테스트**: `next build` 성공 확인
2. **코드 정적 분석**: Grep 기반 패턴 검사
3. **테스트 데이터 시드**: SQL 파일로 생성 → Supabase에 실행 가능
4. **결과 문서화**: test-result Skill로 기록
